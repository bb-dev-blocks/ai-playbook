# Prompt to start project <name> from scratch

This file needs to be filled by the agent when explicity asked.
This file contains a detailed prompt on how to prompt another agent to help
it recreate this project from scratch.
This file should contain enough seed (or project DNA) to assist an isolated agent
to re-create it.

The finished seed must be **self-contained**: the user can copy this file alone
into another agent and leave the entire project behind.

Use the `seed-prompt` skill to author or refresh this file.
